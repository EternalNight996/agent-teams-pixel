# v0.1.3 — live session binding + task progress

## What changed

- **Live session binding** — both the floater and the working-roles tab subscribe to `ctx.sessions` (`ObservableSnapshot<SessionListSnapshot>`) via `useSyncExternalStore`. The `current` SessionId is now the single source of truth for `一键组队` and `申请增配`. The v0.1.2 fallback to `window.__DSH_ACTIVE_SESSION__` and the `prompt()` dance is gone — when no session is active the floater tells the user instead of silently failing.
- **Task progress widget** — the floater now renders a per-team progress bar that aggregates task statuses (✅ / 🔧 / ⏳ / ✕) plus the highest review/repair round count. The `blockedRatio > 50% && in_progress === 0` heuristic raises a `⚠ 多数阻塞` warning; the `escalated` flag flips it to `⚠ 已升级`. Each team row in the list also shows `completed/total` inline.
- **Recent presets** — the working-roles tab memorizes the last 5 presets the user started into `localStorage` (`agent-teams-pixel:recent-presets:v1`). They appear as one-click chips under the goal textarea; the most recent first; corrupt JSON is swallowed so the panel never breaks.

## Compatibility

- New client peer: `@deepseek-ai/dsh-api-session-controller@^0.1.2-alpha.2` (already in the dev set, just being used).
- `SessionListPhase` enum (`'pending' | 'ready'`) honored in the no-store stub.
