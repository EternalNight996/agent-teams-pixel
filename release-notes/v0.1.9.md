# v0.1.9 — published + installable

## What changed

- **Renamed to unscope `agent-teams-pixel`.** The earlier `@eternal-night/agent-teams-pixel` name requires the npm `@eternal-night` org to exist; the `eternalnight` user has the unscope form instead, and the npmjs error path is clearer from a unscope name. `cordis.patch.yml` and the bundled IIFE both now register the unscope id.
- **Real npm publish.** `npm publish --ignore-scripts` succeeded; `npm view agent-teams-pixel` returns the metadata. The package is reachable at `https://registry.npmjs.org/agent-teams-pixel/-/agent-teams-pixel-0.1.8.tgz` (current published: 0.1.8; 0.1.9 follows once this release-notes is committed and `pnpm verify` passes).
- **Real `npm install` round-trip.** An isolated `atp-install-test` directory under `%TEMP%` ran `npm install agent-teams-pixel --legacy-peer-deps` and confirmed: `lib/client.js` IIFE bundle head reads `id: "agent-teams-pixel"`, `cordis.patch.yml` survives the tarball, `assets/` + `release-notes/` are intact.
- **`assets/readme/VISUAL.md`** — a textual walkthrough of every UI affordance the floater renders (title bar, canvas, progress bar, team list, task DAG, inbox, action buttons) and the working-roles tab (一键组队 panel + role grid + search + 中/EN). Used by the README in place of bundled screenshots.
- **`assets/agent-teams-pixel/README.md`** — documents the bundled catalog files (roles.json / roles-full.json), how the captain uses them, and how a maintainer would regenerate after upstream merges new cards.
- **`README.md` "Risks & known limits" section.** Enumerates the alpha.2-only assumption, the `--legacy-peer-deps` install constraint, the polling-not-streaming nature of the floater, the bundled (not fetched) role catalog, the deliberately absent AI chatter route, and the one-shot archival recovery.
- **`README.md` install section** now includes npm badge + the unscope install command + the npm registry link.
