# v0.1.24-rc.1 — Harness 0.2.1 compatibility

Prerelease channel: npm `next`. Recommended host: Harness `0.2.1-rc.1`.

- Support Harness `0.2.1-rc.1` managed subagent creation and targeted recursive cancellation, retaining legacy host adapters.
- Restore member persona and tool restrictions before the first request and after cold recovery. Persist exact member setup and refuse recovery when required setup is missing.
- Restore live member persona and custom tool restrictions after plugin configuration reload, after registering the tools required by saved policies.
- Apply member delegation limits to the new activation API. Preserve native completion/error notifications and existing successful-report deduplication.
- Pin the full development host cohort and align Cordis, Schemastery and plugin-group dependencies.

Validation scope and limitations: [migration record](../docs/harness-0.2.1-rc.1/README.md).

Install the published version with `dsh plugin --profile web add --save-exact @nanmicoder/dsh-agent-teams@0.1.24-rc.1`. This prerelease does not move npm `latest`.
