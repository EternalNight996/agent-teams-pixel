# v0.1.5 — keyboard + settings + retry + archived

## What changed

- **Settings namespace `agent-teams-pixel`** — host registers `{ collapsed: boolean, includeArchived: boolean }` via the canonical `ctx.settings.register` (Schemastery-validated, with `base: { collapsed: true, includeArchived: false }`). The browser half binds through `ctx.settingsScope.bind({ namespace })` once per `apply()`, following the pattern from dsh-ui-three-body and dsh-ui-agents-pixe. Floater collapse state and the archived toggle persist across reloads and dsh restarts.
- **Keyboard shortcuts** — `Alt+O` toggles the floater; `Alt+R` jumps to the working-roles tab. Bindings ignore Cmd / Ctrl / Shift combos and skip when the focused element is `<textarea>` / `<input>` / `contentEditable`. Dispatched through `window` CustomEvents so `apply()` owns one global listener (one disposal path).
- **Retry on error** — when `reload()` or the team poll fails, the floater shows a red `⚠ <message>` banner with a `重试` button that clears the message and re-polls. The captain-wiring endpoint already returns 200 / 202 / 500 — the retry banner surfaces all three without forcing a page reload.
- **Archived teams toggle** — `📦 仅活跃` / `📦 含归档` chip in the floater body flips `?archived=0` ↔ `?archived=1` on the upstream poll (and our own fallback route). Archived teams surface with the same DAG + inbox + output affordances; the user keeps memory of deleted work.
- **Recent presets 清空** — the `清空` chip next to the recent-presets list wipes both in-memory state and the `localStorage` entry in one click.

## Compatibility

- New peer: `@deepseek-ai/dsh-client-ui-settings@^0.1.2-alpha.2` (optional, falls back to defaults if unmounted).
- New client inject: `'settingsScope'`.
- New host-side dependency: Schemastery default export (already in dev deps).
