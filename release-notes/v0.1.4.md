# v0.1.4 — task DAG + captain inbox + task output

## What changed

- **`/plugins/agent-teams-pixel/team` extends** — the drill-down route now also reads `<stateDir>/<teamId>/inbox/*.jsonl` and ships `{ ...team.json, inbox }`. Lines that fail to parse are dropped silently (durability trumps shape).
- **Task DAG widget** — `TaskDag.tsx`-style SVG component on the floater. Nodes laid out by longest-dependency-path depth; edges drawn as straight lines with arrowheads; status colored (✅ / 🔧 / ⏳ / ✕); hover reveals `subject · status · 第N轮`. Clicking a node opens the **task output fold**.
- **Captain inbox panel** — the floater renders the 5 newest inbox messages from the active team's JSONL. Format `from: <80-char snippet>`. Updates every 5s as long as a team is selected.
- **Task output fold** — modal showing the full `output` of any task you click. Truncated to 4 KB to keep the modal responsive; full output is one copy away from the team.json on disk.

## Why these

The v0.1.x series had agent-teams' events flowing through to the canvas, but the user was still blind to two things the captain already had on disk: the task dependency graph (so they couldn't see *why* something was blocked) and the per-task output (so they couldn't see what each member actually produced). v0.1.4 lifts both into the floater.
