# v0.1.0 — initial release

## What ships

- **Captain-led delegation**: the active session becomes the captain of a multi-agent team.
- **508 role cards** bundled from The Agency + agency-agents-zh (assets/agent-teams-pixel/roles-full.json, ~7.1 MB).
- **Pixel office floater** (shell.overlay): collapsible right-side Canvas 2D renderer with 5 member states (idle / typing / walking / done / error).
- **Working roles tab** (conversation.view): searchable role catalog with a detail modal per role.
- **Dependency-aware tasks** delegated through `@nanmicoder/dsh-agent-teams`' tools (captain decomposes → members claim by `dependencies` → captain evaluates → ship or loop back).
- **Request more help button**: `➕ 申请增配` posts to `/plugins/agent-teams-pixel/request-help`, the captain picks it up next turn.
- **Durable across restarts**: team.json under `<workspace>/.agent-teams/<teamId>/`, per-member inbox JSONL.

## Verified

- 15 / 15 unit tests passing (`node --test test/`).
- typecheck smoke covered by `tsc --noEmit` (alpha.2 dependencies required for full build).

## Compatibility

- DeepSeek Harness **0.1.2-alpha.2** (same baseline as `@nanmicoder/dsh-agent-teams` 0.1.15).

## Known limits (v1)

- AI chatter / custom role generator / settings panel — out of scope; dsh-ui-three-body + dsh-ui-agents-pixe each cover their own concern.
- Full `pnpm install` requires ~20 alpha.2 packages; offline demo runs are not in scope.
