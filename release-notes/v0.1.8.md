## What publish does

When this package lands on npm, `dsh plugin --profile web add @eternal-night/agent-teams-pixel` will:

1. Read `cordis.patch.yml` and apply the two insert rows (host + client).
2. `pnpm install` this package into the profile's node_modules.
3. Mount the host row (registers 13 `agent_teams_*` tools + 9 host endpoints + the `agent-teams-pixel` settings namespace).
4. Mount the client row (registers the `__ModuleLoader__.load({ id: '@eternal-night/agent-teams-pixel' })` IIFE — `shell.overlay` + `conversation.view` + `settings.section`).
5. Inject `slots / sessions / locale / uiConversation / settingsScope`.

The end-user sees a "🏢 像素办公室" floater on the right, a "工作角色" tab, and a "像素办公室" section in settings — exactly the v0.1.7 visuals.
