# v0.1.2 — one-click team composition

## What changed

- **29 bundled team presets** (`src/host/team-presets.ts`) — research / science / aerospace / marketing / security / design / finance / game-dev / supply-chain / qa / product / sales / gis / spatial-computing / healthcare / paid-media / support / legal / operations / data / devops / ai-research / cybersecurity / mobile / frontend / backend / writing / teaching / blockchain. Mirrors upstream @dsh-ui-agents-pixe for muscle-memory continuity.
- **`/plugins/agent-teams-pixel/presets`** — returns the preset list as JSON. Browser half renders the preset as a `<select>` in the working-roles tab.
- **`/plugins/agent-teams-pixel/role-identity?key=...`** — returns the agency-agents full role markdown body for a given role id. The captain pulls this when calling `agent_teams_add_member` so each spawned subagent boots with the role's Identity + Mission + Critical Rules + Deliverables baked into its `executionPrompt`.
- **`/plugins/agent-teams-pixel/start-team`** — POST `{ sessionId, presetName, goal }` resolves the captain and injects a structured prompt on its next turn. The captain's own model turn handles `agent_teams_create / add_member / create_task` in the right order; the user just picks a preset + writes a goal.
- **Working-roles tab** now shows a `🚀 一键组队` panel above the role grid. Disabled until both preset + goal are set; live follow-up feedback (✅ / ❌) right next to the button.
