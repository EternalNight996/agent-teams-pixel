# v0.1.6 — archive resume + clean build artifacts

## What changed

- **`/plugins/agent-teams-pixel/resume-team`** — POST `{ sessionId, teamId, teamName, reason }`. The host resolves the captain from `ctx.agents` and injects a follow-up message asking the captain to call `agent_teams_resume({ teamId, reason })` (for halted teams) or recreate the team from the archived `team.json` (for deleted teams). The captain itself decides which path; the host only delivers the wire.
- **OfficeOverlay ↻ 恢复运行 button** — renders only when `includeArchived === true` AND an active team is selected. Posts to `/resume-team` with the active session + team id + reason (a `window.prompt`). Surfaces `200 / 202 / network` through the existing error banner with retry button.
- **Bundle purity gate widened** — `tsdown.config.ts` adds `@deepseek-ai/dsh-api-session-controller/client`, `@deepseek-ai/dsh-client-ui-settings/client`, `@deepseek-ai/dsh-client-ui-settings-plugins/client`, `@deepseek-ai/dsh-client-store` to `CLIENT_EXTERNALS` so the client bundle refuses to inline them and the runtime loader answers them. Without this, the v0.1.3+ client import would either inline a duplicate runtime instance or fail at bundle time.
- **End-to-end build verified** — `npm install --legacy-peer-deps` + `tsc -p tsconfig.json` + `tsc -p tsconfig.client.json` + `tsdown` produce `lib/index.js` (host), `lib/client/{index,office-state,pixel-canvas}.js` (per-file), `lib/client.js` (52 KB bundled IIFE), `lib/types/**/*.d.ts`. The bundled IIFE registers `window.__ModuleLoader__.load({ id: '@eternal-night/agent-teams-pixel', factory: (require) => { ... exports.apply = apply; exports.inject = inject; ... } })` — the contract dsh web expects.
