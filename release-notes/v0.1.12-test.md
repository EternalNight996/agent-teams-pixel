# v0.1.12-test — fix client bundle abort (empty floater + empty roles tab)

## Root cause

The client bundle declared `ctx.uiConversation` in its `inject` array. The
**dsh web client does not expose `uiConversation` as a cordis service** (the
Slot tree is driven by `conversation.*` slots, not that service). Injecting a
missing service makes cordis **throw during client activation**, which aborted
the whole bundle — so neither the working-roles tab nor the pixel-office
floater mounted. That is why the UI showed "空空如也" (both widgets empty)
while dsh itself booted fine.

Confirmed via the live client Service catalog:
- `slots` ✓ present
- `sessions` ✓ present
- `locale` ✓ present
- `uiConversation` ✗ **absent**

## Change

- `export const inject = ['slots', 'sessions', 'locale']` — `uiConversation`
  removed (it was an orphan copied from upstream `dsh-agent-teams`; the code
  never used it). `settingsScope` stays out of inject (degrades to defaults).
