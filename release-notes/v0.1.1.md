# v0.1.1 — captain wiring

## What changed

- **Live snapshot reuse** — the pixel office floater now fetches `@nanmicoder/dsh-agent-teams`' `/plugins/dsh-agent-teams/state` first and falls back to our own list-only route when upstream is unmounted. Polling 5s yields the full per-team snapshot (members + tasks) without an extra round trip.
- **Real request-help** — the office floater's `➕ 申请增配` button now POSTs a reason prompt to `/plugins/agent-teams-pixel/request-help`, which resolves the captain from `ctx.agents` and injects a user message via `captain.followup(createUserMessage(...))`. The captain reads the hint on its next turn and calls `agent_teams_add_member`. If the captain is offline (page refresh, archived session) the request is queued and accepted with `live:false`; the hint reaches the captain when it spins back up.
- **Escalated indicator** — teams whose `escalated === true` (set by agent-teams' quality-gates when review/repair hits its ceiling) flip the floater title bar red and prefix the team list row with a ⚠️. The captain asks the user to decide; the office surfaces that visually.
