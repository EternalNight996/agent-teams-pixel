# v0.1.7 — settings panel + publish-ready docs

## What changed

- **`settings.section` registered** — the `agent-teams-pixel` namespace now also exposes a settings panel under `设置 → 像素办公室`. The panel reads the same bound scope as the floater through `useSyncExternalStore` and writes through `scope.set`, so toggles stay in sync. Three controls:
  - **默认收起浮层** — `scope.set('collapsed', ...)`
  - **含归档团队** — `scope.set('includeArchived', ...)`
  - **清空最近使用预设** — wipes `localStorage['agent-teams-pixel:recent-presets:v1']`.
  - A static hint surfaces the `Alt+O / Alt+R` keyboard shortcuts so the user can find them outside the floater body.
- **`CHANGELOG.md`** — added a per-release index from v0.1.0 through v0.1.7 so the user can scan what each version shipped without opening the `release-notes/` folder.
- **`README.md` rewritten** — now opens with the architecture diagram, gives a one-line `dsh plugin add` install, lists the 29 presets, documents the keyboard shortcuts, references the settings panel, and surfaces the build / test commands verbatim.
